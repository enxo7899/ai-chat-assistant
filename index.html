Rules the code enforces

  • It never guesses. If no FAQ matches well enough, it offers to pass the question to a person.
  • Bookings are complete or not sent. Date, time, party size, name and a valid phone are checked before anything reaches the team.
  • It stays on topic. Attempts to rewrite its instructions are blocked before any model is called.
  • Every answer shows its source, so the owner can fix a wrong FAQ instead of a prompt.

22 automated tests cover these rules. The same engine runs on WhatsApp.
